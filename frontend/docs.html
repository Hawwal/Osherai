Quickstart

Sandbox endpoints are public and safe for integration testing.

curl -X POST https://osherai.onrender.com/api/infra/v1/sandbox/goals/plan \
  -H "Content-Type: application/json" \
  -d '{"amount":150000,"currency":"NGN","purpose":"rent","deadline":"December 1"}'

Authentication

Production endpoints require an approved API key.

x-osher-api-key: osh_prod_your_api_key_here

Never commit raw API keys. Public examples should use placeholders only.

Sandbox

Sandbox mode is public, mock-safe, and does not move funds.

Production Endpoints

GET/health

Returns infrastructure status, network, contracts, and capabilities.

POST/goals/parse

Parses natural-language savings goals.

POST/goals/plan

Creates a structured savings plan.

POST/nudges/generate

Generates user-facing savings nudges.

POST/tips/generate

Generates practical savings tips.

POST/vault/deposit-intent

Prepares a wallet-safe vault deposit intent.

POST/context/savings-summary

Summarizes savings context for apps and agents.

SDK

const { OsherClient } = require("@osher-ai/sdk");

const osher = new OsherClient({
  baseUrl: "https://osherai.onrender.com",
  apiKey: process.env.OSHER_API_KEY
});

const plan = await osher.createGoalPlan({
  amount: 150000,
  currency: "NGN",
  purpose: "rent",
  deadline: "December 1"
});

Safety Model

  • Osher prepares savings actions; wallets approve transactions.
  • Deposit intents are not custody instructions.
  • Private keys are never requested.
  • Production access is approved before use.
  • Sandbox endpoints do not move funds.
